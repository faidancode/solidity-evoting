# Solidity Voting DApp Learning Repo

This repository is a learning workspace for building a simple voting DApp with Solidity, Hardhat, React, and Wagmi.

The goal is to learn how to design, test, and connect smart contracts to a frontend in a realistic but small project.

## Project Goal

- 1 wallet = 1 vote
- Public results
- Admin-managed candidates

## Learning Scope

This repo focuses on:

- Solidity fundamentals
- Hardhat development and testing
- Smart contract design for voting
- React and Wagmi integration
- Deployment to a test network

## Package Manager

This repository uses `pnpm`.

Recommended setup commands:

```bash
pnpm install
pnpm compile
pnpm test
```
